# Outcome

- Result: **completed.** `packages/harness/src/testing/` ships the deterministic ACP test substrate for phases 23–28: a scriptable mock ACP agent (scenario schema + runner + in-process connector + standalone stdio bin) and a recorded-traffic fixture decode suite, exported via the new `@srgnt/harness/testing` subpath. Pure Node — boundary check passes.
- Mock agent: `MockAgent implements Agent` replays a `Scenario` of 14 directive types against the SDK's `AgentSideConnection` — streaming (`emit_chunks` agent/thought/user), tool calls + updates (incl. out-of-order/unknown id), full-list `plan`, `advertise_commands`, `set_mode`, `request_permission` (asserts allow-vs-cancel branches), `use_terminal` + `read_file` (drive client terminal/fs ports), `sleep`, `crash`, `emit_malformed`, and `expect_prompt`/`expect_cancel` assertions. One runner, two injected hooks (`onCrash`, `rawWrite`), behaves identically in-process and as a real subprocess.
- Standalone bin verified as a **registry custom definition through the Supervisor**: the subprocess suite compiles `dist/testing/mock-agent/bin.js`, registers a `source: 'custom'` `HarnessDefinition`, launches it via `Supervisor.spawnerFor(id)`, and asserts (a) valid ACP initialize→session/new→streamed turn, (b) raw malformed bytes mid-turn are skipped-and-continued by the wrapper, (c) `process.exit(7)` mid-turn surfaces as `ConnectionLost`. Manually confirmed the production build artifact too: `node dist/testing/mock-agent/bin.js --scenario <file>` emits correct JSON-RPC frames over stdio.
- Fixture decode: committed, redacted `fixtures/pi/{simple-prompt,tool-use,cancelled-turn}.jsonl` (srgnt `SessionEvent` envelopes). Suite asserts every frame decodes through the tolerant `readSessionEvent` with zero errors; unknown `kind` and unknown extra **envelope** fields are dropped without failing; the opaque `payload` (unknown ACP update variants) is preserved verbatim — the ARCH-0009 invariant, asserted explicitly. `FrameRecorder`/`recordUpdates` tee a live wrapper turn to redacted envelopes (`redactHomePaths` strips home/`/Users`/`/home` paths); a round-trip test proves recordings decode and contain no machine paths.
- Validation (2026-07-14, all foreground):

  - `pnpm --filter @srgnt/harness typecheck` / `lint` / `build`: clean; boundary check passed; real `dist/testing/mock-agent/bin.js` emitted.
  - Root `pnpm build`: all projects green. Root `pnpm test`: **1282 passed / 0 failed, 1 skipped** (contracts 127, harness 110, runtime 287, desktop 758) — +33 vs. the 1249 harness-inclusive baseline (77→110), no regressions. Post-run `ps`: zero orphan `mock-agent/bin.js` processes (Supervisor `disposeAll` kill-tree confirmed).
- Edge cases from the Validation Plan, all covered: out-of-order `tool_call_update` (unknown id) emitted + delivered; ≥1MB single chunk streams without frame-size issues; fixtures redact home paths before commit; permission directive branches on allow vs reject.
